# App-Gestor-Acad-mico
Gestor Académico🚀 App con Docker para el control total del rendimiento escolar. Permite gestionar tareas por criterios de evaluación, calcular notas reales, usar temporizador Pomodoro y predecir el fin de prácticas (FCT) según festivos. Organización profesional con despliegue en un solo comando.
